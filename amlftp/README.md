# amlftp

Две лабораторные на одном окружении. Зависимости ставятся из корня репозитория:

```shell
uv sync --locked
```

- [lab1](lab1/README.md) — одна цель, `masterCategory`.
- [lab2](lab2/README.md) — мультизадачное обучение: категория, пол, сезон и назначение делят общий cross-attention.

Команды каждой работы запускаются из её каталога через `uv run --project ..`. Образ Docker собирается из корня репозитория.
