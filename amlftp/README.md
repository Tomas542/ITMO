# Мультимодальная классификация: фото и текст

Классификатор категории товара по фотографии и названию. Модальности объединяются двунаправленным cross-attention: запросы одной модальности читают ключи и значения другой. Отдельные головы «только фото» и «только текст» модальности не смешивают и нужны для сравнения в отчёте.

## Задача и данные

Датасет [`ashraq/fashion-product-images-small`](https://huggingface.co/datasets/ashraq/fashion-product-images-small). Поля: `image`, `productDisplayName`. Цель: `masterCategory`, четыре класса — Accessories, Apparel, Footwear, Personal Care. На класс берётся не больше 1500 примеров, разбиение стратифицированное 70/15/15.

Фотографии в датасете — миниатюры около 60 px. Энкодер получает их в размере 224 px, визуальные токены ResNet-18 образуют сетку 7×7.

## Модель

Замороженные ResNet-18 и DistilBERT выдают последовательности токенов. Обучаются проекции в общее пространство, два блока `MultiheadAttention` и классификатор:

- изображение → текст: запросы — клетки фото, ключи и значения — токены названия;
- текст → изображение: запросы — токены названия, ключи и значения — клетки фото.

В классификатор попадают усреднённые выходы этих блоков, а не склейка исходных эмбеддингов. Паддинг названия маскируется. Веса attention рисуются в отчёте и в Gradio.

Каталог `weights/` после обучения содержит `model.pt` (лучшие веса fusion), `last.pt` (состояние для возобновления), `resnet18.pt`, `distilbert/` и кэш токенов. Демо читает этот каталог и не скачивает энкодеры заново.

## Запуск и воспроизведение

Команды ниже рассчитаны на запуск из корня проекта. Seed фиксируется в начале `train.py` до загрузки выборки, разбиения и инициализации модели.

### 1. Окружение

```shell
uv sync --locked
```

### 2. Тесты и типы

```shell
uv run pytest
uv run mypy src
```

### 3. Обучение с нуля

```shell
uv run train.py --seed 42 --epochs 5 --max-per-class 1500 --weights-dir weights
```

Первый запуск скачивает датасет, ResNet-18 и DistilBERT, сохраняет энкодеры в `weights/` и учит cross-attention. Повторный запуск с тем же seed использует кэш токенов. Если сборка PyTorch не видит GPU, обучение идёт на CPU.

### 4. Возобновление

`weights/last.pt` хранит веса, оптимизатор, номер эпохи, историю, seed и состояния генераторов случайных чисел. Команда продолжает обучение со следующей эпохи до `--epochs`. Если в чекпоинте другой seed, скрипт останавливается.

```shell
uv run train.py --seed 42 --resume weights/last.pt --epochs 5 --weights-dir weights
```

Чтобы доучить модель дальше, увеличьте `--epochs`, оставив тот же `--seed`.

### 5. Отчёты и веса

После обучения появляются:

- `reports/report.md` и `reports/report.html` — метрики cross-attention и унимодальных голов, кривые, матрица ошибок и примеры с вероятностями и картами attention;
- `weights/model.pt` — лучшие веса по val macro-F1 для демо;
- `weights/last.pt` — чекпоинт возобновления;
- `weights/resnet18.pt` и `weights/distilbert/` — замороженные энкодеры.

### 6. Демо

```shell
uv run gui.py --weights weights
```

Интерфейс Gradio открывается на порту 7860. Нужны фото и название. Если отчёт уже построен, подставляются примеры из `reports/examples`.

### 7. Docker

Образ не содержит веса: каталог `weights/` исключён через `.dockerignore`. Точка входа принимает режим `gui` или `train`. Без аргумента запускается `gui`.

```shell
docker build -t amlftp .
```

Демо читает веса только на чтение. Если `model.pt` нет, процесс завершается с ошибкой и не создаёт файлы в этом каталоге.

```shell
docker run --rm -p 7860:7860 -v "$PWD/weights:/weights:ro" amlftp gui
```

Обучение пишет чекпоинты в `/weights`, отчёты в `/reports`, а скачанный датасет — в `/app/data`. Эти каталоги монтируются с хоста с правом записи. Seed по-прежнему задаётся до разбиения выборки.

```shell
docker run --rm \
  -v "$PWD/weights:/weights" \
  -v "$PWD/reports:/reports" \
  -v "$PWD/data:/app/data" \
  amlftp train --seed 42 --epochs 5 --max-per-class 1500
```

Возобновление внутри контейнера читает `/weights/last.pt`. Другой `--seed` останавливает запуск.

```shell
docker run --rm \
  -v "$PWD/weights:/weights" \
  -v "$PWD/reports:/reports" \
  -v "$PWD/data:/app/data" \
  amlftp train --seed 42 --resume /weights/last.pt --epochs 5
```
